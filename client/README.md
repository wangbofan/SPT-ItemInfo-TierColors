# SPT-ItemInfo-TierColors（客户端 · 五档配色）

SPT 的客户端插件：把背包 / 仓库 / 交易界面里每个格子，按**物品价值档位**（灰 → 蓝 → 紫 → 橙 → 红）上色，物品名跟着一起变色。

档位**不在客户端算**。本仓库的服务端部分（`server/`，ODT-ItemInfo 4.0 汉化分支）
把每件物品的档位算好，客户端开局拉一次整表。所以本插件必须配那个服务端 mod 一起用。

- 当前版本：**2.3.3**
- 插件 GUID：`justnu.odt.tiercolors`
- 要求：SPT 4.1.x（实测 4.1.6）+ BepInEx 5

---

## 装

1. 先装服务端 `ODT-ItemInfo-4.0`（`SPT_Runtime/user/mods/ODT-ItemInfo-4.0/`）。
2. 把 `ODT-TierColors.dll` 丢进 `BepInEx/plugins/ODT-TierColors/`。
3. 启动游戏，日志出现 `档位表来自 http://...，共 4147 件` 就成了。

档位表拿不到时，插件**不会**改任何颜色，游戏保持原样——不会把界面搞花。

## 2.3.3 改了什么

**客户端代码没变，变的是服务端发下来的档位表。**

档位本来就是服务端算、客户端只负责画。2.3.3 重做了服务端的判档数学，
插件这边只是把版本号对齐（F12 / 日志里看到的版本一致，方便报问题）。

装上新包后你会看到的实际变化：

| 以前 | 现在 |
|---|---|
| 同一件物品这次开服紫、下次开服可能变蓝 | **每次开服完全一样**（基准价不再用跳蚤动态价） |
| 全渠道禁售的稀罕货反而不上色 | 禁售且无货源的吃最高系数，**最低也是紫色** |
| 5.45 `PS`（穿透 28）比 `PP`（穿透 34）颜色更深 | 同口径内**穿透越高档位不会更低**，50 对倒挂全部修掉 |
| 相邻档位门槛差 2.9~3.5 倍，中间档挤成一坨 | 门槛**等比 ×4**（3,000 / 12,000 / 48,000 / 192,000），档与档拉开 |

修完的分布：普通 972 / 少见 1239 / 稀有 1296 / 史诗 487 / 传说 153（共 4147 件）。
你的 F12 颜色设置全部保留，不用重调。

## 2.3.2 改了什么

**五档的透明度统一了。**

2.3.1 及以前，每一档画出来有多透 = 该档自己颜色的 A × 背景不透明度。
A 是每档各写各的（第 1 档默认 0、其余默认 FF），一旦手动调过某一档的 A，
仓库里就会出现「这档浓、那档淡」的花感。

2.3.2 把两件事彻底拆开：

| 颜色的 A | 管什么 |
|---|---|
| `A = 0` | **只管「这一档画不画」** —— 不画 |
| `A > 0` | **只管「这一档画不画」** —— 画 |

画出来有多透，**五档一律用「背景不透明度」那一个值**，写多少 A 都不再影响浓淡。
悬停高亮也只是把 RGB 提亮，A 保持不动，不会一悬停就突然变实。

好处很直接：仓库里蓝紫橙红叠在一起，看起来是同一层玻璃，只是颜色不同。

## 2.3.1 改了什么

**第 1 档从「白」改成「灰」。**

白底压在灰扑扑的仓库面板上其实很吵，而且跟游戏原本的浅色格子几乎分不出来。
第 1 档现在默认是**中性灰 `#8A8A8A`**，A 仍然是 0（默认不画）。想让它显形就把 A 拉上去，
出来是一层很淡的灰，不抢眼，跟后面四档的色阶也接得上。

顺带两处：

- 档位名从「1 普通 · 白」改成「1 普通 · 灰」；旧配置里的 `1 普通 · 白` 键启动时自动清掉，
  不会在 F12 里留一条没用的旧档。
- 灰档的物品名是**跟着底色明暗走的灰**，不是一律甩成死白。

服务端 `config/tiers.json` 的 `COMMON` 也同步从 `default` 改成 `grey`，
两侧对同一档用的是同一个颜色概念。

## 2.3.0 改了什么

**「显示 N 档背景」那一排开关删了。**

以前每一档要理解两样东西：颜色是什么、要不要画。现在合成一件：**颜色自带的 A（Alpha）就是开关**。

| 这一档的 A | 结果 |
|---|---|
| `A = 0`（Hex 结尾 `00`） | **完全不画**。格子连底色都不留，跟没装这个 mod 一模一样 |
| `A > 0` | 按这个颜色画，透明度 = 「背景不透明度」那一个值（2.3.2 起，A 不再影响浓淡） |

默认第 1 档「普通」就是 `A = 0`：满仓库绝大多数是普通物品，全都刷上色会很刺眼。
想让它也有颜色，把 A 拉上去就行，不需要再找别的开关。

**物品名跟着背景色变。**

以前暗色底上还是白字，一深一浅很花。现在格子里那行名字跟背景同一个色系，
但亮度强制提到 0.80 以上、饱和度收一点，压在压暗的底上仍然看得清。
不想要：F12 → `02 高级` → 关掉「物品名跟着变色」，恢复游戏原本的白字。

旧配置里的「显示 N 档背景」会在启动时自动迁移（关着的档位 → A 置 0）然后删掉，
不用手动清 `.cfg`。

## F12 面板

### [00 总开关]

| 项 | 默认 | 说明 |
|---|---|---|
| 启用按价值配色 | 开 | 关掉就完全恢复游戏原本按类别的背景色 |
| 自动检视全部物品 | 开 | 所有物品一律当成已检视，装配界面不再报「无法应用未检视的物品」 |

### [01 五档颜色]

| 项 | 默认 | 说明 |
|---|---|---|
| 1 普通 · 灰 | `#8A8A8A00` | **A = 0，默认不画**；拉上去是一层淡灰 |
| 2 少见 · 蓝 | `#2694DA` | |
| 3 稀有 · 紫 | `#9F5ACF` | |
| 4 史诗 · 橙 | `#FFA726` | |
| 5 传说 · 红 | `#FF3B3B` | |

每一档的颜色就是它自己的开关：`A = 0` 不画，`A > 0` 画。

### [02 高级]

| 项 | 默认 | 范围 | 说明 |
|---|---|---|---|
| 背景亮度 | **0.55** | 0.10 – 1.00 | 五档一起压暗/提亮。1.00 = 原色最鲜，0.20 = 接近黑灰只剩一点色 |
| 背景饱和度 | **0.55** | 0.00 – 1.00 | 鲜艳程度。1.00 = 原色，0.00 = 完全灰白只剩明暗 |
| 背景不透明度 | 0.75 | 0.15 – 1.00 | **五档共用的透明度**，格子底色透不透。低于 0.4 会看不清图标 |
| 物品名跟着变色 | 开 | — | 名字用同色系提亮色；关掉就是原版白字 |
| 配件最多升 1 档 | 开 | — | 见下 |
| 打印调试日志 | 关 | — | 排查用，平时开着日志会很大 |

**觉得太鲜艳就调「背景亮度」和「背景饱和度」**，两个都拉到 0.2 左右基本就是很淡的一层灰调。
调色只动明度和饱和度，**色相不变**——蓝还是蓝、红还是红。
调整后已画出来的格子会立刻换色，不用重启。

## 怎么算一件物品的颜色

1. 服务端给每个 `tpl`（物品模板 ID）一个 1–5 的档位。
2. 客户端按档位取颜色，再乘「背景亮度 / 饱和度」，透明度统一取「背景不透明度」。
3. **配件加成**：一件物品最终按「自己 + 身上所有**插槽**里最高的那一档」上色。
   - 只走插槽（Slot）——弹匣里的子弹、背包里的东西不算。
   - 递归最多 8 层。
   - 开着「配件最多升 1 档」时：灰枪身 + 红色瞄具 → 蓝色（不会一步跳红）。
   - 关掉：灰枪身 + 红色瞄具 → 直接红色。

拆件、装件、换弹之后会自动重算，不用手动刷新。

## 配置在哪

`BepInEx/config/justnu.odt.tiercolors.cfg`，F12 改完立即写盘。

从 v1.x（十档版本）或 2.3.0（第 1 档叫「1 普通 · 白」）升级上来时，配置里会残留旧键。
2.3.1 启动时会自动清掉 `1 普通 · 白` 这一条；更老的 `[01 等级背景色]` / `[01 等级颜色]` 段
BepInEx 会直接忽略，不影响使用。嫌乱可以整个删掉该 `.cfg`，下次启动会按新结构重建。

## 与服务端的分工

| 颜色 | 谁管 | 存哪 |
|---|---|---|
| 格子背景 + 格子里那行物品名 | **客户端**（本插件） | `justnu.odt.tiercolors.cfg` |
| 物品详细描述里的名字富文本 | 服务端 | `SPT_Runtime/.../ODT-ItemInfo-4.0/config/tiers_hex.json` |

两边各自独立：想改格子里的颜色按 F12，想改服务端文案里的名字色去改 `tiers_hex.json`。

## 排障

| 现象 | 原因 / 办法 |
|---|---|
| 完全没颜色 | 服务端没装或没启动；F12 看「启用按价值配色」是否关掉；日志搜 `ODT-TierColors` |
| 某一档明显比别的档淡/浓 | 2.3.2 起不会了：A 只决定画不画。若还这样，确认 DLL 是 2.3.3 |
| 只有部分物品有色 | 正常——第 1 档默认 A = 0，普通物品不上色 |
| F12 里还剩「显示 N 档背景」 | 旧配置残留，重启一次游戏会自动迁移掉 |
| F12 里还剩「1 普通 · 白」 | 旧版键名残留，重启一次游戏会自动清掉 |
| 名字颜色刺眼 | F12 → 02 高级 → 关掉「物品名跟着变色」 |
| 颜色对不上档位 | 服务端配置里 `customRarity` 手工覆盖了该物品 |
| 想恢复原版界面 | F12 关掉「启用按价值配色」，或直接删插件 |
